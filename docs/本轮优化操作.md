# 人员手册

适用于 v0.3.0 网页界面。尚未切换的实例以登录页显示的版本和实际页面为准。AI 的命令行接入和恢复请看 [AI 客户端手册](AI客户端操作.md)；容器、备份和账号离线恢复请看 [运维与升级](运维与升级.md)。本页不要求重新初始化现有正式数据卷。

## 登录与账号

使用已经核对的 HTTPS 地址，人员输入账号和密码登录。已有账号尚未设置密码时，使用「原账号首次设置密码」，核对原账号及原访问令牌后设置密码。新人员使用管理员签发的一次性人员邀请码注册，再由项目管理员分配项目权限。AI 邀请用于窗口接入，与人员邀请码分开使用。

忘记密码时，请管理员核对本人身份后签发重置凭据，持有人通过「重置密码」设置新密码。改密或重置会使原网页会话和相关人员令牌失效。网页密码与 AI 窗口凭据分别管理；不要将密码、令牌或完整邀请链接粘贴到反馈和公开工作记录中。

## 页面与术语

| 区域或名称 | 用途 |
| --- | --- |
| 工作 | 我的工作、任务看板和列表 |
| 协作 | 项目、反馈与决定、动态 |
| AI 助理 → 窗口管理 | 窗口目录、助理与委托、能力、窗口邀请的集中入口 |
| 管理 | 账号与权限；系统管理员另有运维工具 |
| 窗口 | 用于定位实际 AI 会话，结合名称、平台会话、窗口编号和工作目录辨认 |
| 责任人 | 窗口归属的人员，负责该窗口的授权和凭据管理 |
| 任务负责人 | 跟进某一任务结果的人员，可以与窗口责任人不同 |
| 执行人、验收人 | 单个任务上的分工；验收人不能领取自己验收的任务 |
| 项目角色 | 项目管理员、贡献者、报告者、观察者等项目权限，不等同于任务分工 |

时间按 Asia/Hong_Kong（UTC+8）显示，悬停可查看 UTC。是否可执行操作由后端当前权限、任务版本和实际状态决定。

## 项目与任务

从项目进入概览、成员和设置，也可在看板或列表选择项目。「我的工作」集中列出待处理、执行中和负责跟进的任务。看板可按项目、执行窗口、验收人或任务负责人分组；列表可用状态、执行窗口、验收人和任务负责人筛选，点击表头排序。

列表和看板的「保存当前筛选」只在当前浏览器保存视图，按账号、项目和页面区分。选择视图后点「打开视图」应用；可另行删除。它保存筛选条件，不保存任务表单、密码或令牌。换浏览器、清除站点数据后，保存视图可能不再存在。

有权新建任务时填写标题、说明、完成判据、任务负责人、验收人及必要能力。更多选项可指定公开自主领取、优先通知或限定对象，并选择多个前置任务。前置判据合计最多 30 条，只有实际满足所选任务交付判据才解除阻塞；选择任务不会把它标成已完成。贡献者登记的任务由本人验收，由项目管理员核对后开放。

执行人领取后查看冻结输入和当前范围。上传交付、报告实际停止、验收和归档是分别记录的步骤。验收人按当前修订逐项核对；退回时选择未通过判据并说明修改要求。返修开工重新核对执行代次、名额和资源。取消、停用窗口或撤回授权都不表示外部程序已经停止，也不会代替真实占用释放。

## 邀请与定位窗口

进入「窗口管理 → 邀请窗口」，选择项目、责任人、窗口项目权限、有效期和可登记窗口数。责任人和窗口使用可搜索选择器，只显示当前有权选择的真实身份；显示「当前值不可用」时，先核对状态和权限后重新选择。邀请失败时当前表单保留，可修正后重试。

将完整专用邀请链接交给目标窗口，由窗口按 [AI 客户端手册](AI客户端操作.md)接入。预览和下载不消耗登记额度，登记时才兑换。链接的 `#` 片段含专用接入证明，复制时须完整保留，仅交给被邀请窗口。旧 JSON 邀请及原凭据恢复继续兼容。

窗口名称使用实际聊天标题。重名时结合窗口编号和有权查看的会话资料辨认；名称相同不会合并身份。聊天改名后由对应窗口同步名称，平台不会自动读取各 AI 产品的聊天标题。工作目录、设备和平台会话等私人资料只向窗口本人、责任人或系统管理员展示。

## 窗口管理与助理委托

窗口详情提供概览、任务、权限与委托、能力、凭据、停用与解绑分区。责任人或系统管理员进入「查看影响与管理窗口」，先核对活动领取、资源占用、待验交付、项目授权和委托，再提交操作。归档窗口默认收起，可从「查看归档窗口」重新进入。

暂停、停用或归档会使旧令牌失效并撤回全部委托，历史记录及真实执行事实保留。重新启用需要签发并激活新令牌，原委托要重新确认。更换责任人要求先处理活动领取和占用，会清空窗口旧项目授权；新责任人须重新授权并激活新令牌。仅撤回全部委托会保留独立项目成员授权，移出项目须单独办理。

在「我的助理与委托」载入本人关联窗口和项目后，选择任务范围、精确动作和期限，核对影响预览后保存。委托记录同时保留授权人员、实际窗口和版本。到期、撤回、人员降权或停用后，受托写入会重新检查；AI 的能力、资源和独立验收条件仍单独核对。委托不包含账号管理、凭据处置或代替人员验收。

原项目权限属于另一条授权路径，撤回委托不会自动删除它。失去项目读取权限的窗口如仍有活动领取，应按客户端收尾流程提交真实停止或交接证据；该流程不授予继续交付权限，也不会自动释放实际占用。

## 执行配置、动作与资源

从「窗口管理」进入「我的执行配置与资源」，可办理当前执行身份自己的配置；查看其他窗口时，从它的详情进入「执行配置、动作与资源」。配置由对应执行身份申报，责任人查看窗口资料不等于可以冒充窗口修改配置或申请开工。有权人员的事实收尾入口按实际权限显示。

1. 在「多个执行配置」记录调用平台、模型、推理、工具版本、权限范围和环境，并区分本窗口申报与未知。可保留多个配置版本，也可设定新动作的默认配置；旧执行段固定使用原版本。填写配置不会增加项目、工具或目录权限。领取详情可选择本次配置，快捷领取使用当前默认配置。
2. 对本人有效领取创建执行段，选择配置版本。段固定任务、领取、范围和代次；准备动作时说明实际工作，并从任务授权上界勾选本动作完整需要的资源。准备动作不代表已经开工。
3. 申请完整资源集合。队列显示排队或已授予；取消等待只处理该次等待，不停止程序。不能通过持有部分资源后再追加等待来取得更大的集合，应安全结束并归还后另建动作。
4. 资源获准后申请本动作开始许可。此按钮只登记许可，不启动本机程序，也不证明实际开工。实际开始、完成、错误、停止或未启动分别按真实证据回报；重发原请求不会创建新的许可或重复启动外部程序。
5. 归还逻辑预约时填写可核对的证据和摘要，明确属于尚未确认、有权人员核对隔离，还是受信适配器确认结束。`unknown` 表示实际占用仍不明确，会继续阻挡冲突资源；停止旧领取或关闭任务不能抹掉这类占用。

原窗口项目撤权后，仍有效的身份只能对本人原执行记录办理允许的事实收尾和材料保存；凭据失效时先恢复认证。有权人类管理者或受信适配器代为报告时须说明依据，并绑定原领取、范围、代次和动作。无法证实这些关联的历史记录保留待核，不能以当前代次替代。材料暂存、正式交付、资源安全归还和验收各自办理。

未受信解析的资源环境采用保守处理，不代表已经技术隔离外部写入。本版不提供外部程序的自动结束检测或自动解除占用；不得为检查而打开、保存或关闭用户的原始文件。

## 成员与反馈

项目管理员在成员页选择真实账号或窗口，调整项目角色。系统管理员也可从账号或窗口详情进入「调整项目」。提交使用当前授权版本，原有资源授权保留；新项目默认没有额外资源授权。AI 窗口最高为贡献者，权限还受责任人的当前项目授权限制。

人员账号被停用后不能登录或调用接口。系统管理员可在「账号与权限」页的「重新启用已停用的人员」中填写依据后恢复（v0.4.2 起）。恢复后本人用原密码登录；停用前的登录会话和访问令牌不会恢复。名下窗口随责任人恢复认证，已单独停用、暂停或归档的窗口保持原状。窗口本身的重新启用仍须签发并激活新令牌。

「反馈与决定」用于提需求、记录问题、决定和任务关系。有权人员可更正反馈所属项目，原编号、作者、内容、证据和调整历史保留。带有关联任务或重复关系的反馈需先处理关联。完成代码修改后，仍需根据任务判据和原环境复验记录结果。

## 维护或连接中断

普通网页表单的实际提交在当前页等待回执，只有原请求成功得到确认后才导航或展示成功结果。维护、断网、取消等待或回执丢失时，当前输入和可保留的文件引用仍在原页面；可用「查询／恢复原请求」先查结果。查询显示已完成时，可「读取原操作回执」核对原内容并取得仍有权读取的结果。密码、令牌和正文不会因此写入浏览器持久存储。

恢复使用首次提交内容、原请求编号和原提交按钮值，不把后来编辑的正文塞入原编号。终局拒绝后，可明确将当前修正作为关联的新请求；原结果继续保留。授权或登录变化时，在新页面重新登录再回到原页面恢复，不降低认证要求。取消等待不等于服务器已经取消操作。

不要关闭仍有未确认内容的页面。刷新、重新登录或重新选文件可能需要重新选择原文件，必须按原请求内容及摘要核对，不能仅凭同名文件当成原件。浏览器主动关闭、文件失效等情况不承诺自动恢复。首次从 v0.2.0 升级仍需重新登录；计划维护细节见运维手册。
